## 协议摘要

单条报文 = 8 字节固定头 + 变长载荷，**小端序**，总长 **≤ 1200 字节**。

| 偏移 | 长度 | 字段 | 说明 |
|---|---|---|---|
| 0 | 2 | `Magic` | `0x55 0x44`（ASCII `"UD"`） |
| 2 | 1 | `Version` | 当前 `0x01` |
| 3 | 1 | `Type` | 消息类型 |
| 4 | 2 | `Seq` | 发送序号，`0–65535` 回绕 |
| 6 | 2 | `PayloadLen` | 载荷长度，`0–1192` |
| 8 | N | `Payload` | 长度 = `PayloadLen` |

### 消息类型

| 值 | 名称 | 方向 | 说明 |
|---|---|---|---|
| `0x01` | `HELLO` | C → S | 上线 / 重连 |
| `0x02` | `HELLO_ACK` | S → C | 上线确认 |
| `0x03` | `HEARTBEAT` | C → S | 心跳，1 s 一次 |
| `0x04` | `HEARTBEAT_ACK` | S → C | 心跳响应 |
| `0x05` | `DATA` | 双向 | 业务数据 |
| `0x06` | `BYE` | 双向 | 主动下线 |
| `0x07` | `ANNOUNCE` | S → 广播 | 服务端宣告 |
| `0x08` | `ANNOUNCE_ACK` | C → S | 客户端收到宣告 |

未知类型一律忽略，不回包。

### 校验规则

接收长度记为 `n`，任一条件不满足即丢弃：

- `8 ≤ n ≤ 1200`
- `Magic == 0x5544`
- `Version` 可识别
- `8 + PayloadLen == n`

### 会话与超时

- 会话键：`(IPv4, 端口)`
- 心跳间隔 1 s，服务端 5 s 未收到任何报文即移除会话
- 超时判定使用单调时钟
